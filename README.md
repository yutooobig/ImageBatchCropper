# ImageBatchCropper - 图片批量裁剪工具

一个简单易用的图片批量裁剪工具，支持多种裁剪方式和输出格式。

## 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行程序
```bash
python main_optimized.py
```

### 打包版本
已打包的可执行文件位于 `dist/` 目录：
- `ImageBatchCropper.exe` - 图形界面版本
- `ImageBatchCropperCmd.exe` - 命令行版本

## 使用方法

1. 选择图片文件夹
2. 设置裁剪参数（单位、裁剪值）
3. 选择输出文件夹
4. 点击开始裁剪
